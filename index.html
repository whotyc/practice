StudyHelperBot
Главная О проекте Участники Журнал Ресурсы

Telegram-бот для учёбы и продуктивности

StudyHelperBot — проект на Python, который помогает студентам вести задачи, хранить заметки и управлять расписанием прямо в Telegram.

Описание проекта Журнал работы
Python Aiogram 3 SQLite HTML/CSS Git + Markdown

Функции бота

  • 📌 Список задач и дедлайны
  • 🧠 Заметки и быстрый поиск
  • 📅 Расписание занятий
  • 📊 Статистика выполненных задач
  • 📚 Хранение данных в SQLite

Проект разработан в рамках проектной (учебной) практики, 2026.

Зачем нужен StudyHelperBot?

📌 Организация задач

Бот помогает не забывать о дедлайнах, хранит список задач и позволяет быстро отмечать выполненные.

🧠 Хранение заметок

Можно сохранять конспекты и идеи прямо в Telegram, без сторонних приложений.

📅 Расписание

Расписание занятий хранится в базе данных, его можно редактировать и просматривать в любой момент.

Технологии проекта

⚙️ Backend

Python + Aiogram 3, асинхронная обработка команд и сообщений.

🗄 База данных

SQLite — хранение задач, заметок и расписания пользователей.

📄 Документация

Markdown, Git, журнал прогресса и руководство по запуску проекта.
