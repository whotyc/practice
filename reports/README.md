# Отчёты по проектной практике

В данной папке размещены отчёты по проектной практике в бинарных форматах.

## Содержимое папки

### report.docx
Основной отчёт по проектной практике в формате Microsoft Word.

### report.pdf
PDF-версия отчёта по проектной практике.

---

## Назначение файлов

Файлы содержат:
- описание проекта;
- цели и задачи практики;
- описание выполненной работы;
- результаты проектной практики;
- выводы по выполненному проекту.
