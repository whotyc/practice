# Отчёт о тестировании

## Проведённые проверки

В рамках тестирования были проведены следующие виды проверок:

- тестирование механики распространения листовок;
- проверка корректности работы диалоговой системы;
- тестирование системы сохранений;
- анализ пользовательского интерфейса.

---

## Выявленные проблемы

В процессе тестирования были обнаружены следующие недостатки:

- отдельные ошибки анимации;
- повторяющиеся диалоговые реплики;
- недостаточная вариативность поведения NPC.

---

## Предложения по доработке

Для повышения качества проекта предлагается:

- расширить набор диалогов;
- улучшить элементы интерфейса;
- увеличить количество игровых заданий;
- доработать вариативность взаимодействия с персонажами.
