# История изменений проекта

## Общая информация

Данный документ содержит сведения об основных изменениях, внесённых в проект в процессе разработки.

Файл предназначен для фиксации этапов развития проекта, реализованных функций, исправленных ошибок и планируемых обновлений.

# Версия 0.1 — Этап предпроизводства
Дата: март 2026

## Добавлено

- создана структура проекта;
- подготовлена базовая проектная документация;
- сформирована концепция игрового проекта;
- определены основные игровые механики;
- подготовлена дорожная карта разработки.

## Выполнено

- анализ аналогичных игровых проектов;
- распределение ролей внутри команды;
- создание Git-репозитория проекта.

# Версия 0.2 — Вертикальный срез
Дата: май 2026

## Добавлено

- система перемещения персонажа;
- базовая диалоговая система;
- механика распространения листовок;
- система взаимодействия с NPC;
- система автоматического сохранения прогресса.

## Обновлено

- структура проектной документации;
- описание игрового процесса;
- концепция пользовательского интерфейса.

## Исправлено

- ошибки обработки взаимодействия с NPC;
- проблемы сохранения игрового состояния;
- отдельные ошибки анимации.
