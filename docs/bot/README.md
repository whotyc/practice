# Проект: MosPolyStudyHelpBot

## Описание проекта

MosPolyStudyHelpBot — Telegram-бот, предназначенный для помощи студентам в организации учебного процесса.

Бот позволяет:
- создавать расписание занятий;
- добавлять заметки;
- создавать задачи;
- отмечать задачи как выполненные;
- просматривать статистику выполненных задач.

Проект разработан в рамках проектной практики студентами Московского политехнического университета.

---

# Цель проекта

Целью проекта является создание удобного инструмента для организации учебной деятельности студентов с использованием Telegram-платформы.

---

# Задачи проекта

В ходе выполнения проектной практики были поставлены следующие задачи:

- изучить основы работы Telegram Bot API;
- освоить библиотеку aiogram;
- разработать Telegram-бота;
- реализовать систему хранения задач и заметок;
- реализовать систему расписания;
- подготовить документацию проекта;
- освоить Git и GitHub;
- оформить репозиторий проекта.

---

# Используемые технологии

В проекте использовались следующие технологии:

- Python
- aiogram
- Telegram Bot API
- Git
- GitHub
- Markdown
- HTML/CSS
