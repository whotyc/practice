# Документация по проектной практике

## Проект MosPolyStudyHelpBot

MosPolyStudyHelpBot — Telegram-бот, разработанный для помощи студентам в организации учебного процесса. Проект выполнен в рамках проектной практики студентами Московского политехнического университета.

Бот позволяет пользователям организовывать учебную деятельность через привычный интерфейс Telegram. В рамках проекта был реализован функционал создания расписания занятий, добавления заметок, управления задачами и отслеживания статистики выполнения задач.

---

## Цель проекта

Целью проекта является разработка Telegram-бота, упрощающего организацию учебного процесса студентов.

## Описание функционала

### Работа с расписанием

Пользователь может создавать расписание учебных занятий, просматривать сохранённые пары и изменять записи.

### Работа с заметками

Бот предоставляет возможность сохранять текстовые заметки для хранения учебной информации и быстрого доступа к ней.

### Работа с задачами

Пользователь может создавать задачи, отслеживать их выполнение и отмечать выполненные задачи.

### Статистика

Бот отображает статистику выполненных задач, что позволяет анализировать продуктивность пользователя.
