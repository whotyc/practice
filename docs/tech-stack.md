# Технологический стек проекта

## Основные технологии

В процессе разработки проекта используются следующие технологии и инструменты.

---

## Языки программирования

### C#

Используется для реализации игровой логики, механик и взаимодействия между системами проекта.

### Python

Применяется при разработке Telegram-бота в рамках вариативной части проектной практики.

---

## Игровой движок

### Unity

Используется в качестве основной среды разработки игрового проекта.

Основные причины выбора:

- широкие возможности разработки;
- поддержка 2D и 3D;
- развитая экосистема;
- наличие документации и сообщества.

---

## Система контроля версий

### Git

Используется для:

- отслеживания изменений;
- командной разработки;
- хранения истории проекта.

---

## Платформа размещения репозитория

### GitHub

Применяется для хранения исходного кода, документации и организации совместной разработки.

---

## Средства разработки

### Visual Studio

Используется для написания и отладки программного кода.

### Blender

Применяется для подготовки 3D-моделей и графических материалов.

### Figma

Используется при разработке интерфейсов и концепт-артов.

---

## Документация

### Markdown

Применяется для ведения проектной документации и оформления технических материалов.
