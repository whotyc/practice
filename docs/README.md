# StudyHelperBot

## Описание проекта

StudyHelperBot — Telegram-бот, разработанный для помощи студентам в организации учебного процесса. Бот позволяет управлять расписанием занятий, создавать заметки, добавлять задачи и отслеживать прогресс их выполнения.

Проект выполнен в рамках проектной практики студентами Московского политехнического университета.


## Основные функции

- создание расписания занятий;
- добавление и просмотр заметок;
- создание задач;
- отметка выполненных задач;
- просмотр статистики выполнения задач;
- удобное взаимодействие через Telegram.


## Используемые технологии

- Python
- Telegram Bot API
- Git/GitHub
- Markdown
- HTML/CSS
