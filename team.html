Участники проекта

Проект выполнен командой из двух человек в рамках проектной практики.

Попова Елизавета

Разработка бота и сайта

Реализация Telegram-бота StudyHelperBot на Python (Aiogram 3), создание базы данных SQLite, разработка функционала задач, заметок и расписания. Создание и оформление сайта проекта (HTML + CSS) в соответствии с требованиями практики.

Бородина Екатерина

Разработка документации

Подготовка документации проекта в формате Markdown: инструкции по установке и запуску, описание структуры репозитория, журнал прогресса, оформление итоговых материалов и отчёта по практике (DOCX + PDF).

Распределение задач

Работа выполнялась параллельно: разработка кода и сайта проводилась Поповой Елизаветой, а оформление документации и отчётности — Бородиной Екатериной. Оба участника вели коммиты в общий репозиторий.
